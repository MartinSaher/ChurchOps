# مؤتمراتي — النسخة 2 (بناء APK من GitHub)

## أول مرة (أو لو بتبدأ Repository جديد)
1. ارفع **كل محتويات** المجلد ده على Repository في GitHub (مع `www` و`assets` و`.github` وملف `debug.keystore` وملف `.gitignore`).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
3. بعد ما يخلص (✅)، نزّل **mo2tamarati-apk** من قسم Artifacts، فك الضغط وثبّت `app-debug.apk`.

## لو عندك Repository قديم
استبدل الملفات دي بس: `www/index.html` و`www/sw.js` و`package.json` و`.github/workflows/build-apk.yml`، وضيف ملف **`debug.keystore`** في أول المشروع. بعدها شغّل **Build APK**.

## مهم جدًا: التحديث من غير ما تخسر بياناتك
- ملف **`debug.keystore`** هو مفتاح توقيع التطبيق. طول ما كل نسخة جديدة بتتبني بنفس الملف ده، هتثبّتها **فوق** القديمة من غير ما تمسح التطبيق وبياناتك بتفضل زي ما هي.
- **أول مرة** هتنزّل نسخة موقّعة بالمفتاح الجديد: لازم تمسح النسخة القديمة (اللي اتبنت بمفتاح تاني) قبل التثبيت. **قبل ما تمسحها** خُد نسخة احتياطية: الإعدادات ← **نسخ كنص** والصقه في ملاحظة، أو **حفظ كملف** لو النسخة القديمة فيها الزرار. وبعد التثبيت: الإعدادات ← **استرجاع**.
- احتفظ بنسخة من `debug.keystore` في مكان آمن، واخلي الـ Repository **Private**.
- كل Build بيرفع رقم النسخة تلقائيًا، فالتحديث بيتقبل دايمًا.

## بعد كده
- النسخة الاحتياطية: **الإعدادات ← حفظ كملف** وابعته لنفسك على واتساب أو درايف. التطبيق بيفكّرك على الرئيسية لو عدّى وقت من غير نسخة (بتتحكم في المدة من الإعدادات).
- لو الـ Build فشل (❌)، افتح الشغل وابعتلي آخر سطور الخطأ.
